# Simple Interest Calculator

## Description

This project is a simple interest calculator that calculates the simple interest and total amount using the principal amount, rate of interest, and time.

## Formula

**Simple Interest = (P × R × T) / 100**

Where:

* **P** = Principal Amount
* **R** = Rate of Interest
* **T** = Time in years

## Example

If:

* Principal = ₹10,000
* Rate = 5%
* Time = 2 years

Then:

**Simple Interest = (10000 × 5 × 2) / 100 = ₹1,000**

**Total Amount = ₹10,000 + ₹1,000 = ₹11,000**

## Features

* Easy to use
* Calculates simple interest
* Calculates total amount
* Beginner-friendly project
